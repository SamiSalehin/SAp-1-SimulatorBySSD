⚙ SAP-1 Manual

How to Use This Simulator

Step 1 — Load a Program into RAM

Click the blue 16×8 RAM block or Edit RAM. Choose a preset or manually enter instructions.

Step 2 — Run or Step Through

Press RUN to execute automatically. Use NEXT/PREV to single-step. Press PAUSE to freeze anytime.

Reading Pin Strips

Every component shows its input pins below the value. When a pin is inactive it shows grey. When it is logically 1 it glows green. When it is actively being used this T-state it glows amber and pulses.

Arrow Bit Labels

Animated arrows show data moving between blocks. The binary value being transferred appears above each arrow. The W-bus also shows its current contents on the side label.

SAP-1 Architecture Theory

SAP-1 (Simple As Possible 1) by Albert Paul Malvino demonstrates the fetch-decode-execute cycle on an 8-bit bus architecture.

Fetch-Decode-Execute

T1 — PC → MAR (Ep=1, L̄M=0)
T2 — PC++ (Cp=1)
T3 — RAM[MAR] → IR (C̄E=0, L̄I=0)
T4–T6 — Execute per opcode
